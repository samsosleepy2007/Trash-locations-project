# React Bits

Components adapted for this NRRU website from https://reactbits.dev/ .

- ClickSpark: fetched from https://reactbits.dev/r/ClickSpark-JS-CSS.json
- CardSwap, ShapeBlur, SplitText: source supplied by the user in promt.txt
- Changes: scoped/on-demand spark rendering; controlled card index and shorter transitions; reduced-motion support; lazy WebGL with idle/visibility cleanup; progressive enhancement of the existing static map.
