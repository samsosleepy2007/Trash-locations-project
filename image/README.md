# Location images

ใส่รูปของแต่ละจุดในโฟลเดอร์นี้ตามเลขหมุดบนเว็บไซต์

- จุดที่มีรูปเดียว: `1.png`, `2.png`, `3.png` ...
- จุดที่มีหลายรูป: `2-1.png`, `2-2.png`, `2-3.png` ...
- ระบบรองรับสูงสุด 5 รูปต่อจุดในรูปแบบ `N-1.png` ถึง `N-5.png`
- ถ้ามีไฟล์ `N.png` ระบบจะถือว่าเป็นรูปเดี่ยวและใช้ไฟล์นั้นก่อน
